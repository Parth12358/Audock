Set up Audock — an AI-maintained, Obsidian-compatible Markdown knowledge base — in the current folder.

1. Download the `audock` CLI for my OS from the latest release and put it on my PATH (or at ./tools/audock):
   https://github.com/Parth12358/Audock/releases/latest
   (macOS: audock-macos-arm64 · Linux: audock-linux-x86_64 · Windows: audock-windows-x86_64.exe)
   On macOS/Linux: chmod +x it.
2. Run `audock init` here to scaffold the vault. If this is already an Obsidian vault, run
   `audock init --dry-run` first and show me what it would change — it's additive and never
   overwrites my files.
3. Read the CLAUDE.md it creates — that's your librarian protocol. Follow it from now on:
   - Before answering factual questions, probe the vault with `audock context ""`.
   - To save something: `audock ingest`, then the dedup gate `audock similar`, distill an atomic
     note, link it, `audock reindex`, and commit to git.
   - Never edit a note marked `locked: true` (or inside  regions).
4. Confirm it works by running `audock doctor` and show me the result.

Paste into Claude Code (or Claude) from inside the folder you want to turn into a knowledge base.

Or set it up yourself

  1. Download the binary above, chmod +x it, and put it on your PATH as audock.
  2. In a new or existing Obsidian vault: audock init --dry-run to preview, then audock init.
  3. Make it a git repo if it isn't: git init && git add -A && git commit -m "add Audock".
  4. Capture something: audock ingest <file|url|-> --type web, then audock new note "Title".
  5. Ask it things: audock context "your question" · tidy it: audock doctor.
  6. In Obsidian, enable the Dataview plugin (and Obsidian Git for auto-backup).

What you get

Two-layer & lossless

Verbatim, immutable sources/ + distilled atomic notes/. Recoverable three ways: hashes, append-only logs, git.

Cheap for the AI

One audock context call returns a bounded answer pack — Claude answers without reading whole files.

SQL bulk edits

SELECT / UPDATE / MERGE over your notes, dry-run by default, never touching human-owned notes.

Human-owned stays yours

Mark notes locked: true and the AI treats them strictly read-only.

Obsidian-native

Wikilinks, tags, graph color-groups, and Bases .base views — no lock-in.

Self-healing

doctor finds orphans, broken links, stale notes, dup/tag variants; reindex keeps maps fresh.
