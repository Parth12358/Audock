set up with claude
Set up Audock — a Markdown knowledge base you maintain for me — in the current folder.

1. Download the audock CLI for my OS from the latest release and put it on my PATH
   (or at ./tools/audock): https://github.com/Parth12358/Audock/releases/latest
   (macOS: audock-macos-arm64 · Linux: audock-linux-x86_64 · Windows: audock-windows-x86_64.exe).
   On macOS/Linux, chmod +x it.
2. Run `audock init` here. If this is already an Obsidian vault, run `audock init --dry-run`
   first and show me — it's additive and never overwrites my files.
3. Read the CLAUDE.md it creates and follow it from now on: before answering a factual
   question, probe with `audock context ""`; to save something, `audock ingest`,
   then `audock similar`, distill a note, link it, `audock reindex`, and commit to git.
   Never edit a note marked `locked: true`.
4. Run `audock doctor` and show me the result.

What it does

Loses nothing
Verbatim sources, append-only notes, and full git history — recoverable three ways.
Cheap to ask
One command returns a bounded answer, so your AI reads far less to respond.
Stays yours
Mark a note locked and the AI treats it as read-only — it never edits what you own.
Opens in Obsidian
Wikilinks, tags, and a graph that colors itself by topic. No proprietary format.
Edits in bulk
A small SQL dialect over your notes — select, update, and merge, dry-run by default.
