# Tags vs links

Only `[[links]]` create graph edges; `#tags` do not. So a parallel hierarchical tag taxonomy mostly duplicates what wikilinks and [[maps-of-content]] already do. Keep tags to a few typed scalars (domain, status) and let links carry navigation.
