# Atomic notes

An atomic note captures exactly one concept, so it can be linked from any note that touches that concept. Atomicity is what makes [[evergreen-notes]] reusable and lets a [[dedup-gate]] reason about one idea at a time. Audock's [[two-layer-store]] applies the same rule to its distilled layer.
