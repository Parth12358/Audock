# Stable note IDs

Links keyed on filenames break when a note is renamed. The durable pattern is an immutable `id` in frontmatter, a human-readable title as the filename, and `aliases` for alternate names. This supersedes [[timestamp-filenames]], and underpins Audock's resolver and [[markdown-as-source-of-truth]].
